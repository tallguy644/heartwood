Shop admin

Connect your inventory

Your inventory lives in your GitHub repo. Paste a GitHub access token once on this device and the Publish button can update your live site.

How to make a token (2 minutes)
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and tap Generate new token.
  2. Name it "Tilley Woodworks admin". Set an expiration you're comfortable with.
  3. Under Repository access, choose Only select repositories → heartwood.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate, copy the token and paste it here.

The token is saved only in this browser on this device. It can only change the heartwood repo, and you can revoke it on GitHub any time.
